# Minimal React Native - Expo template pre-configured with NativeWind (v4)

I made this because setting up a new React Native project with Expo and NativeWind can is surprisingly time-consuming. This template is pre-configured with NativeWind (v4) and a default theme.

## How to use

- Clone this repository and run `yarn` or `npm install` to install dependencies.
- Make it yours by :
  - deleting the `.git` folder and running `git init` to start a new git repository.
  - editing the `app.json` file to change the app name, slug, and other settings.
  - editing the `tailwind.config.js` file to customize the theme (find good themes at [Tweakcn](https://tweakcn.com/)).

## Note

NativeWind v4 only supports tailwind v3 (requires tailwind.config.js), if you want to use tailwind v4,
you have wait till NativeWind v5 is stable.
